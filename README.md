# WCAG Brand Contrast Analyzer
A Java-based accessibility tool featuring a Swing graphical user interface.

## Overview
As an undergraduate software engineering student minoring in graphic design, I built this application to bridge the gap between technical development and visual aesthetics. This tool programmatically calculates the Web Content Accessibility Guidelines (WCAG) contrast ratio between brand colors to ensure digital accessibility. 

## Technical Skills Demonstrated
* **Java:** Object-Oriented Programming (OOP) and Java Swing UI development.
* **UI/UX Design:** WCAG compliance, digital accessibility, and brand strategy implementation.
